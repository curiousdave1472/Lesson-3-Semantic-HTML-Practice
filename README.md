## Semantic HTML Practice
Our current Todo list is a pretty poor example of semantic HTML. Change the HTML code to utilize the appropriate semantic HTML elements.

Once we implement the appropriate HTML, we can probably also remove the `<br>` tags (since our elements will create better spacing for us by default). `<br>` is called a break tag and it is no longer considered best practice to use them. We should be accomplishing our spacing using semantic HTML and CSS alone. Feel free to add additional spacing with your HTML is you'd like.
